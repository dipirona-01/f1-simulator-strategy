# f1-simulator-strategy

# 🏎️ F1 Strategy Lab

Um simulador de estratégias de corrida inspirado na Fórmula 1, desenvolvido para praticar programação e manipulação do DOM com JavaScript.

## ⚙️ Funcionalidades

- Escolha do número de voltas.
- Seleção de estratégia com 1 ou 2 paradas.
- Escolha de pneus para cada stint.
- Distribuição automática das voltas.
- Cálculo ilustrativo do desgaste dos pneus.
- Resumo da estratégia e dos resultados da corrida.
- Validação dos dados inseridos.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎮 Como utilizar

1. Informe o número de voltas.
2. Escolha a estratégia de paradas.
3. Selecione os pneus de cada stint.
4. Clique em **Simular Estratégia**.
5. Confira o resumo e os resultados.

## 📌 Objetivo

Projeto desenvolvido com o objetivo de praticar HTML, CSS e JavaScript por meio da criação de um simulador interativo inspirado no automobilismo.
